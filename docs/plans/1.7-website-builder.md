# Website Builder: Professional Output + Onboarding Preview

## Context

Two problems with the current website builder:

1. **Bare-bones output quality.** The LLM prompt has good design intent but the generated sites look amateurish. Root causes: `max_tokens=8192` causes the model to truncate the CSS before finishing; no concrete CSS code patterns are given (only prose descriptions); images use random Unsplash IDs that may 404; no JavaScript animations; no mobile responsiveness specified precisely.

2. **No preview in the onboarding flow.** After the AI generates the site, the onboarding page shows nothing — the user only gets a "Finish & go to dashboard" button. The *dashboard* website page already has a proper split-pane chat + iframe preview, but onboarding doesn't. The user has no idea what was built until they leave onboarding.

Both are improvements to the existing website builder (V1_SPEC §7). No new routes, tables, or services needed.

---

## Fix 1 — Prompt quality (`backend/app/agents/website_builder.py`)

### Change `max_tokens` from 8192 → 16000

A full professional site (HTML + CSS) commonly runs 10,000–14,000 tokens. 8192 cuts it short, producing truncated CSS and missing sections.

```python
def _llm() -> ChatAnthropic:
    return ChatAnthropic(
        model="claude-sonnet-4-6",
        anthropic_api_key=settings.anthropic_api_key,
        temperature=0.3,
        max_tokens=16000,
    )
```

### Rewrite `SYSTEM_PROMPT_TEMPLATE`

Replace the current prompt with a version that:

- **Gives concrete CSS patterns, not just prose.** Include literal CSS variable definitions, font-face links, card styles, and button styles as examples — not descriptions.
- **Requires a specific 5-section page structure:** (1) Nav, (2) Hero with gradient background, (3) Services/Features grid, (4) Social proof / About, (5) Footer with contact info. Each section described concretely.
- **Removes the Unsplash ID gamble.** Instead: use CSS gradient backgrounds for the hero, and SVG icons or emoji for service cards. No external images that can 404 and break the layout.
- **Requires `<meta name="viewport">` and 2 responsive breakpoints** (`max-width: 768px` and `max-width: 480px`) so the site looks good on mobile.
- **Requires a small vanilla JS scroll-reveal animation** using `IntersectionObserver` — adds one `data-reveal` class with a fade-in transition.
- **Requires the HTML to inline the CSS** in a `<style>` tag so the single-file preview works perfectly in the iframe. `index.html` must be fully self-contained.

Key sections of the new prompt:

```
━━━ REQUIRED PAGE STRUCTURE ━━━
1. <nav> — logo left, 3–4 links right. Sticky. White bg with subtle box-shadow on scroll.
2. <section class="hero"> — full-viewport-height. CSS gradient background matching brand colour.
   Large bold headline, 1-sentence subtext, one CTA button.
3. <section class="services"> — 3-column CSS Grid of cards.
   Each card: icon (emoji or simple SVG), title, 2-sentence description.
4. <section class="about"> — 2-column layout: left = bold stat or quote, right = business paragraph.
5. <footer> — business name, tagline, nav links, contact info. Dark background.

━━━ REQUIRED CSS SETUP ━━━
:root {
  --color-primary: #2563eb;   /* adjust for brand */
  --color-accent:  #f59e0b;
  --color-bg:      #f8fafc;
  --color-text:    #1e293b;
  --color-muted:   #64748b;
  --radius:        12px;
  --shadow:        0 2px 16px rgba(0,0,0,0.08);
  --max-width:     1180px;
}

━━━ REQUIRED FONT LOADING ━━━
<link href="https://fonts.googleapis.com/css2?family=Inter:wght@400;500;600;700&family=Playfair+Display:wght@700&display=swap" rel="stylesheet">

━━━ NO EXTERNAL IMAGES ━━━
Do NOT use <img> tags with external URLs. Use CSS gradient backgrounds and emoji/SVG icons.

━━━ SCROLL ANIMATION ━━━
const observer = new IntersectionObserver(els => els.forEach(e => {
  if (e.isIntersecting) e.target.classList.add('visible');
}), { threshold: 0.15 });
document.querySelectorAll('[data-reveal]').forEach(el => observer.observe(el));

CSS: [data-reveal]{opacity:0;transform:translateY(24px);transition:opacity .6s ease,transform .6s ease}
     [data-reveal].visible{opacity:1;transform:none}
```
